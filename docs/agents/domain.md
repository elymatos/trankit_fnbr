# Domain docs

This repository uses a single-context domain-documentation layout.

Before exploring, read these when they exist:

- `CONTEXT.md` for domain vocabulary and boundaries;
- applicable ADRs under `docs/adr/`.

If they do not exist, proceed silently. Domain-modeling skills create them
when terminology or architectural decisions need to be recorded.

Use terminology defined in `CONTEXT.md`. Explicitly identify proposals that
conflict with an existing ADR.
